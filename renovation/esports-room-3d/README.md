# 电竞房 · 可交互 3D

真 3D（WebGL / Three.js）：可旋转、缩放、走进去；拉远可看「盒子屋」俯视。

## 运行

```bash
cd renovation/esports-room-3d
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/`。

## 两套配色（右上角一键切换）

| 主题 | 特点 |
|------|------|
| 深红赛博 | 黑色家具、深红灯带、WE 灯牌、红色管线、俄罗斯方块灯 |
| 白色马里奥 | 银灰铝板保留；白色桌柜/层板/坐垫；中性白灯光；洞洞板彩色可拆模块；问号块、砖块、蘑菇、星星、水管 |

也可用地址参数直达：`http://localhost:5173/?theme=white`

## 操作

| 模式 | 操作 |
|------|------|
| 环视旋转 | 拖拽旋转 · 滚轮缩放 · 右键平移 |
| 走进房间 | 点击锁定 · WASD 走动 · Esc 退出 |
| 门口视角 / 俯视走向 | 一键切到对应机位 |

## 布局（对齐平面图）

坐在电脑前时：
- **面朝**：左墙双升降电竞桌、曲面屏、WE 灯牌、洞洞板
- **背后**：右墙 L 形**卡座书架**（软包长凳 + 百叶窗 + 两侧书架塔），顶墙一段短肢
- 入口墙：玻璃展示柜；中央圆形地毯

## 模型细节

- 电竞椅：头枕、侧翼、腰部红条、扶手、气压杆、五星脚轮
- 桌面：曲面 27" 显示器、背光键盘、鼠标垫、耳机架、桌沿红光
- 侧透主机（红色风扇）、俄罗斯方块灯、红色工业管线
- 材质：拉丝铝板、清漆抛光地砖、皮革/网布、玻璃；环境反射 + 柔和泛光

## 结构

```
src/main.js       场景装配、灯光、相机、后处理
src/furniture.js  主题调色板 + 家具模型（椅、桌、显示器、主机、卡座、书架、窗、展示柜、马里奥道具…）
src/textures.js   程序化贴图（金属、地砖、洞洞板、壁纸、窗景、Logo、问号块、砖块、蘑菇…）
```
