# 电竞房 · 可交互 3D（按你家户型）

真 3D（WebGL / Three.js）：可旋转、缩放、走进去；拉远可看「盒子屋」俯视。房间按你提供的平面图 1:1 建模。

## 运行

```bash
cd renovation/esports-room-3d
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/`（默认法拉利配色）。

## 户型（对齐平面图，北为 -Z）

| 位置 | 内容 |
|------|------|
| 左墙（西） | 两张 1.5m **升降电竞桌**并排，各配一台侧透主机 + 曲面屏 + 键鼠；上方吊顶内嵌**长条灯槽**（对应 SketchUp 白模） |
| 顶墙（北） | 2.2m **飘窗**做背景：深窗台 + 皮革坐垫 + 抱枕 + 窗帘，窗外黄昏城市天际线；东北角结构柱 |
| 右墙（东） | **L 形卡座**：窗下一段无靠背长凳接窗台，东墙一段带靠背，绕柱而过；上方两层展示层板；靠门处方向盘背光挂板 + 头盔层板 |
| 入口墙（南） | 2.2m **展示架**（模型车 / 头盔）+ 上方两层层板；右侧**夹丝玻璃偏轴门**（东南角，向西厨外开） |
| 中间 | 卡座前轮毂茶几（法拉利）/ 圆桌；条纹地毯 |

尺寸：室内约 3.4m × 4.0m，层高 2.8m，四周 0.5m 吊顶边带（2.5m），线性空调风口在门侧吊顶。

## 操作

| 模式 | 操作 |
|------|------|
| 环视旋转 | 拖拽旋转 · 滚轮缩放 · 右键平移 |
| 走进房间 | 点击锁定 · WASD 走动 · Esc 退出 |
| 门口视角 / 电竞桌 / 飘窗卡座 / 俯视走向 | 一键切到对应机位 |

## 模型细节

- 电竞椅：头枕、侧翼、腰部红条、扶手、气压杆、五星脚轮
- 桌面：曲面 27" 显示器、背光键盘、鼠标垫、耳机架、桌沿灯带、**桌面主机**（开放式机箱：主板、显卡 RGB、CPU 光环、内存条、前置三风扇、侧透玻璃）
- 飘窗：突出 0.55m 的窗台盒、石材台面、黑框分格玻璃、坐垫 + 抱枕、窗帘杆、窗台下灯带
- 偏轴门：黑框、夹丝玻璃（网格贴图）、长拉手、外开
- 材质：碳纤维、清漆抛光地砖、皮革/网布、玻璃；环境反射 + 柔和泛光

## 结构

```
src/main.js       户型常量、房间壳体（吊顶边带 / 灯槽 / 柱子 / 开窗开门）、家具摆位、灯光、相机、后处理、主题切换
src/furniture.js  主题调色板 + 家具模型（椅、桌、显示器、主机、卡座、飘窗、偏轴门、轮毂茶几、头盔、模型车、方向盘、马里奥道具…）
src/textures.js   程序化贴图（碳纤维、地砖、洞洞板、壁纸、盾徽、天际线、条纹地毯、夹丝玻璃…）
```
