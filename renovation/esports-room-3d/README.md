# 电竞房 · 可交互 3D

这是**真 3D**：WebGL 场景，可旋转、缩放、走进去。不是平面效果图。

## 运行

```bash
cd renovation/esports-room-3d
npm install
npm run dev
```

浏览器打开终端提示的本地地址。

## 操作

| 模式 | 操作 |
|------|------|
| 环视旋转 | 拖拽旋转 · 滚轮缩放 · 右键平移 |
| 走进房间 | 点击锁定 · WASD 走动 · Esc 退出 |
| 门口视角 / 俯视走向 | 一键切到对应机位 |

风格：深红赛博。

布局（对齐平面图）：
- 左墙：双升降电竞桌（人面向左墙）
- **右墙 + 顶墙 L 形卡座书架：在电脑正后方（椅背后对面）**
- 入口墙：展示架
- 中央：圆形地毯
