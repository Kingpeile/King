# 电竞房装修效果图 + 可交互 3D

## 重要区别

| 类型 | 是什么 | 在哪 |
|------|--------|------|
| 平面效果图 PNG | 看起来像 3D，但是**静态图片**，不能转 | `esports-room/*.png` |
| **真 3D 模型** | WebGL 场景，可拖拽旋转 / 走进去 | `esports-room-3d/` |

之前只给了平面效果图，所以你会觉得「没有立体感」。要立体感请打开可交互模型。

## 真 3D 怎么打开

```bash
cd renovation/esports-room-3d
npm install
npm run dev
```

浏览器打开提示的地址。右上角可切换 **深红赛博 / 白色马里奥** 两套配色，然后：
- **拖拽**旋转（真立体）
- **滚轮**缩放
- **走进房间**：WASD 走动
- **门口视角 / 俯视走向**：一键切机位

## 布局（已按平面图修正）

坐在电脑前时：
- **面朝**：左墙电竞桌 / 屏幕
- **背后**：右墙 L 形**卡座书架**（在椅背正后方，不是侧面）
- 顶墙还有一段卡座短肢
- 入口墙：展示架
- 中央：圆形地毯动线
