# 电竞房装修效果图 + 可交互 3D

## 重要区别

| 类型 | 是什么 | 在哪 |
|------|--------|------|
| 平面效果图 PNG | 看起来像 3D，但是**静态图片**，不能转 | `esports-room/*.png` |
| **真 3D 模型** | WebGL 场景，可拖拽旋转 / 走进去 | `esports-room-3d/` |

之前只给了平面效果图，所以你会觉得「没有立体感」。要立体感请打开可交互模型。

## 真 3D 怎么打开

```bash
cd renovation/esports-room-3d
npm install
npm run dev
```

浏览器打开提示的地址。右上角可切换 **法拉利 Rosso Corsa（默认）/ 深红赛博 / 白色马里奥** 三套配色，然后：
- **拖拽**旋转（真立体）
- **滚轮**缩放
- **走进房间**：WASD 走动
- **门口视角 / 电竞桌 / 飘窗卡座 / 俯视走向**：一键切机位

## 布局（已按你家平面图 1:1 建模）

- **左墙（西）**：两张升降电竞桌并排，各一台桌面主机 + 曲面屏；上方吊顶灯槽
- **顶墙（北）**：2.2m 飘窗做背景，深窗台坐垫 + 抱枕；东北角结构柱
- **右墙（东）**：L 形卡座绕柱（窗下一段 + 东墙一段带靠背）；靠门处方向盘挂板
- **入口墙（南）**：展示架靠左；夹丝玻璃偏轴门在东南角，外开向西厨
- **中间**：卡座前茶几 + 地毯动线

详见 `esports-room-3d/README.md`。
