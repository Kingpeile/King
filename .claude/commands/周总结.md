做我的「笔记周总结」。我的笔记都在「笔记同步助手」文件夹里，按日期命名。

规则：
- 已有笔记只读，绝不改写或删除。
- 只新建一份报告，存成「笔记同步助手/_周总结-<本周结束日期>.md」，不在别处建文件夹。

【双链铁律 —— 必须能点进去】
- 凡是提到某条笔记，一律写成 `[[精确文件名]]`，文件名用你在文件夹里**实际看到的那个**
  （去掉 .md 后缀），一个字都不能改、不能用描述代替。
  例：看到文件叫 `2026-06-10 Hermes Agent.md`，就写 `[[2026-06-10 Hermes Agent]]`。
- 写描述性的假链接（如 `[[Hermes 方案]]`）= 死链，绝对禁止。
- 拿不准某条的精确文件名，就别给它做双链，用纯文字提一句即可，别瞎编文件名。

任务（一次别读太多正文，否则会触发长上下文报错、又慢又卡）：
1. 列出最近 7 天新增的笔记，这 7 天的可以读全文。
2. 对比历史时**不要批量读历史正文**——只看文件名/标题/标签判断相关性，
   只有某一两条明显相关时才去翻那一两条正文确认。

【报告主体 = 成对连接】不要只给笼统的主线概括，要给**一对一的具体连接**：
每一条都写成「本周 [[A]] ←→ 历史 [[B]]」的成对形式，两边都是可点双链，再写两句：
- 🔁 重合 / 📈 递进 是哪种、具体重合或推进在哪
- 这条连接**说明你在往哪个方向走 / 接下来值得深挖什么**（这一句是「再深一点」的关键，别省）

最后核对：每个双链的文件名是不是真实存在的？说的重合/递进是不是真有其事？
不确定的宁可不写，别硬凑。看不到「笔记同步助手」文件夹就直接说，别凭空编。

报告模板：

```markdown
# 📊 周总结（<起> – <止>）

## 本周新增（<N> 篇）
- [[精确文件名]] — 一句话它在记什么

## 成对连接

### 🔁 重合 / 又在关注的
- 本周 [[A]] ←→ 历史 [[B]]
  - 重合点：<具体在哪重合>
  - 信号：<这说明你在反复关注什么 / 值得深挖什么>

### 📈 递进 / 往前推了一步
- 本周 [[C]] ←→ 历史 [[D]]
  - 怎么推进：<具体深化、补充、往前推在哪>
  - 信号：<这条线在往哪走 / 下一步可以做什么>

## 本周方向
- 反复出现的关注点：<…>
- 最值得深入的一条线：<…>
```
