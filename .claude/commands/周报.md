做我的「本周周报」,回答一个问题：**这周我干了什么。**
把我这台机器上本周的活动，揉成一份报告。

## 数据源（都在本地，全部只读，绝不改/删原文件）

1. **Claude Code 终端会话**：`~/.claude/projects/` 下本周修改过的 `*.jsonl`
2. **Codex 会话**：`~/.codex/` 下本周的会话日志（一般在 `~/.codex/sessions/` 里的 `*.jsonl`）
3. **Hermes**：`笔记同步助手/_聊天/` 下本周的 `hermes-*.md`(Hermes 自己写进来的对话）
4. **笔记**：`笔记同步助手/` 下本周新增的笔记

## 铁律

- 所有源**只读**。唯一要**写**的，是这份周报：`周记/周报 <起> 至 <止>.md`
  （沿用我现有的命名和文件夹，无缝替代我手动贴的那份）。
- **绝不一次把原始 `.jsonl` 全读进来**——那会触发长上下文报错、又慢又卡。必须分步压缩（见下）。

## 怎么走（分步，这是防上下文爆炸的关键，别跳）

1. **定窗口**：本周 = 最近 7 天（`<起>` 到 `<止>`,以今天为止往前 7 天）。

2. **逐源逐文件压成短摘要**——**一次只读一个文件**,读完写 3–5 行摘要到
   `笔记同步助手/_周报缓存/<源>-<文件名>.md`,然后**丢掉原文再读下一个**。
   绝不同时把多个原始会话抱在手里。每条摘要只记：
   - 这次聊/做了什么主题
   - 有什么决定、产出、进展
   - 有什么没解决、待办

3. **合成**：所有源压完后，**只读这些短摘要 + 本周新笔记**,合成周报。

4. **核对**：说的事是不是真有其事?引用的旧笔记/会话是否真实存在?不确定的不写，别硬凑。

5. **清场**：写完把 `笔记同步助手/_周报缓存/` 删掉（临时文件，不留）。

## 周报结构（回答「这周我干了什么」）

```markdown
# 周报 <起> 至 <止>

## 这周我干了什么（按事/项目归类，跨工具）
- <一件事>:在 Claude Code / Codex / Hermes 里聊了/做了…，进展到…
- <另一件事>:…

## 聊得最多的几件事
- <主题>:反复出现，主要在 <哪个工具> 里推进

## 新存的笔记 & 和过去的呼应
- 本周新增：[[精确文件名]] — 一句话
- 🔁 又在关注：本周 [[A]] ←→ 过去 [[B]],<重合点>
- 📈 往前推了：本周 [[C]] ←→ 过去 [[D]],<怎么推进的>

## 没干完 / 下周接着
- <待办、悬着的事>

## 信号
- 这周我主要的注意力花在了：<…>
```
（提到笔记一律用 `[[精确文件名]]` 双链，文件名照实际的写，点不进去的死链不要。）

## 边界

- 某个源这周没内容 → 跳过，写一句「本周无」,别硬编。
- 某个路径看不到（比如这台没装 Codex / 没有 `_聊天/` 文件夹）→ 跳过那一项，别报错停住。
- 看不到 `笔记同步助手/` → 直接说「这里看不到你的笔记」,别凭空造报告。
