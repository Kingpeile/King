帮我做一份近期健康小结。我的健康记录在「健康病历」文件夹里。

## 数据源（只读，绝不改/删原文件）

- **健康记录**：`健康病历/` 下近期（约最近 30 天，或自上次小结以来）的笔记/记录。
- 看不到 `健康病历/` 就直接说，别凭空编。

## 无人值守铁律

- 不准问问题，自己判断决定，绝不调用 AskUserQuestion 停下等我。
- 一轮要短：一条条看，抓指标、症状、用药、就医记录，别逐字精读无关内容。
- 原文只读。唯一写的是小结（见下）。

## ⚕️ 安全红线（重要）

- **不下医疗诊断、不开药、不替代医生。** 你只做两件事：**如实汇总**和**温和提醒**。
- 可以指出「这个指标在变化 / 这个症状反复出现 / 这项该复查了」,但用「值得关注 / 建议找医生看看」的措辞，
  **绝不**说「你得了 X 病」「这是 Y 的征兆」这类判断。
- 拿不准的、数据不足的，老实说「记录不够，看不出趋势」,别吓人也别糊弄。

## 怎么走

1. 按类型归拢近期记录：指标（体重/血压/血糖/睡眠…）、症状、用药、就医/检查。
2. **找变化和趋势**:哪些指标在往好/往坏走?哪些症状反复出现?和更早的记录比，用 `[[精确文件名]]` 双链引出处。
3. **标出值得关注的点**:按红线措辞，温和提醒哪些该留意、哪些该复查/找医生。
4. 给一两条**可执行的小建议**(作息、记录得更全、该约的检查），具体、不空泛。

## 输出

写到 `健康病历/_健康小结-<本次日期>.md`(下划线开头排最前）。

```markdown
# ⚕️ 健康小结（<起> – <止>，生成于 <YYYY-MM-DD>）

## 指标 & 趋势
- <指标>:<最新值/变化> ，对比 [[更早记录]]:<往好还是往坏>

## 反复出现 / 值得关注
- <症状或指标>:<怎么个反复/异常法> → 值得关注，建议找医生看看

## 该复查 / 该约的
- <项目>:<上次什么时候，该复查了>

## 小建议
- <具体、可执行的一两条>
```

## 边界

- 近期没有健康记录 → 写一句「近期没有新的健康记录」,别硬造。
- 看不到 `健康病历/` → 直接说，别编。
- 任何时候不确定 → 老实说不确定，并建议「以医生意见为准」。
