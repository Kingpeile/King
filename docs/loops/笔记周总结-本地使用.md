# 笔记周总结 · 本地使用说明

你的真实笔记在你自己电脑/手机的 Obsidian 里（文件夹「笔记同步助手」），没传到这个云端仓库。
所以这个循环要在**你本地的 Obsidian 文件夹**里跑。

## 怎么用（三步）

1. 在电脑上，找到你 Obsidian 笔记所在的文件夹（里面有「笔记同步助手」这个子文件夹）。
2. 在那个文件夹里启动 Claude Code。
3. 把下面整段指令复制粘贴进去，回车。

> 不需要再给它「Loop 橙皮书」——下面这段指令是自包含的，照着做就行。

## 复制这段给本地的 Claude Code

```
你是我的「笔记周总结」助手。我的 Obsidian 笔记都在「笔记同步助手」这个文件夹里，按日期命名。
请帮我做最近这一周的总结报告。

规则（重要）：
- 「笔记同步助手」里已有的笔记，只读，绝对不要改写或删除。
- 你唯一要新建的，是一份周总结报告，存成「笔记同步助手/_周总结-<本周结束日期>.md」，
  放在同一个文件夹里。不要在别的地方建文件夹。

任务：
1. 找出「本周新增」的笔记（文件名日期或 frontmatter 日期落在最近 7 天内的）。
2. 把这些新笔记，和文件夹里过去已有的笔记对比，找出两种关系：
   - 🔁 重合：我又在关注同一个主题 / 反复出现的关注点。
   - 📈 递进：我这周把过去某条笔记的想法，深化、补充、或往前推了一步。
3. 按下面格式写报告，引用别的笔记用 [[双链]]。
4. 写完回头核对：你说的「重合 / 递进」是不是真有其事？引用的旧笔记是否真的存在？
   不确定的关系宁可不写，别为了凑数硬扯。
5. 如果你看不到「笔记同步助手」这个文件夹，直接告诉我，不要凭空编报告。

报告格式：

  # 📊 周总结（<起> – <止>）

  ## 本周新增
  - [[<日期/标题>]] — 一句话

  ## 和过去的呼应
  ### 🔁 重合 / 又在关注的
  - 本周 [[A]] 与过去 [[B]]：都在讲 <主题>。<一句点出重合点>
  ### 📈 递进 / 往前推了一步
  - 本周 [[C]] 把过去 [[D]] 的想法推进了：<具体怎么深化 / 补充的>

  ## 信号
  - 这周反复出现的关注点：<…>
  - 值得深入的方向：<…>
```

## 想每周自动跑、不用每次粘贴？

跑顺了之后，可以让它每周自己跑一次。那一步要配一点东西，回到这个对话找我，我帮你弄。
