# 让笔记周总结「自己转」· 本地 /loop

> 前提：你的笔记在本地 Obsidian，所以这个循环在**你电脑上**跑。
> 电脑开着、Claude Code 开着时它自己转；关了就停。要「关机也跑」得把笔记上云，先不弄。
> 需要 Claude Code v2.1.72 以上（`/loop` 是这个版本之后才有的命令）。

---

## 一行就够（因为你已经有 `/周总结` 命令了）

`/loop` 可以直接定时执行一个 slash command。你已经有 `/周总结`,所以不用再单独写
任务文件，直接：

```
/loop 7d /周总结
```

= **每 7 天自动跑一次 `/周总结`**。它自己醒来、自己扫新笔记、自己出报告，然后等下一轮。
你在循环外面，它自己在里面转。这就是完整的 loop：发现 → 生成 → 验证 → 持久化 → **调度**。

---

## 先小步验一下（别等一周）

正式挂 `7d` 之前，先用 2 分钟一轮看它**真的会自己醒来**：

```
/loop 2m /周总结
```

它每 2 分钟自动跑一次 `/周总结`。看它自动转一两轮、报告正常生成，
按 `Esc` 或 `Ctrl + C` 停掉。确认没问题，再换成 `7d` 正式挂上。

---

## 记住两件事

- **它只在你电脑 + Claude Code 开着时转**。关机就停，下次开机再 `/loop 7d /周总结` 起来。
- 第一次跑，盯着看它有没有乱动你的笔记（应该只新建 `_周总结-*.md`,不碰别的）。
  放心了，以后就让它自己转。
- 想升级成「关机也跑、完全不用管」——回对话找我，那一步要把笔记上云，我带你弄。
