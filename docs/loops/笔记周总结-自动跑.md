# 让笔记周总结「自己转」· 本地 /loop

> 前提：你的笔记在本地 Obsidian，所以这个循环在**你电脑上**跑。
> 电脑开着、Claude Code 开着时它自己转；关了就停。要「关机也跑」得把笔记上云，先不弄。
> 需要 Claude Code v2.1.72 以上（`/loop` 是这个版本之后才有的命令）。

---

## 第一步：先感受「它自己转」（2 分钟体验，不产生任何文件）

在你 Obsidian 文件夹里启动 Claude Code，敲这一行：

```
/loop 2m 看一眼「笔记同步助手」文件夹有没有新增笔记，有就列出来，没有就说一句没有
```

它会**每 2 分钟自己醒来一次**，自己看一眼，自己报告，然后自己接着等下一轮——
你什么都不用做，就看着它转。这就是 loop 的感觉：**你在循环外面，它自己在里面转。**

看够了，按 `Esc` 或 `Ctrl + C` 停掉。（这步只是体验，不会动你的笔记。）

---

## 第二步：换成真正的「每周笔记总结」

1. 在你 Obsidian 文件夹里建一个文件：`.claude/loop.md`
2. 把下面这段粘进去、保存：

```
做我的「笔记周总结」。我的笔记都在「笔记同步助手」文件夹里，按日期命名。

规则：
- 已有笔记只读，绝不改写或删除。
- 只新建一份报告，存成「笔记同步助手/_周总结-<本周结束日期>.md」，不在别处建文件夹。

任务：
1. 找出最近 7 天新增的笔记。
2. 和文件夹里过去的笔记对比，找出 🔁 重合（又在关注同一主题）和 📈 递进（把旧想法往前推了）。
3. 写成报告，引用别的笔记用 [[双链]]。
4. 写完核对：关系是不是真有其事？引用的旧笔记是否存在？不确定的宁可不写，别硬凑。
5. 看不到「笔记同步助手」文件夹就直接说，别凭空编。
```

3. 然后敲这一行，让它每周自己跑：

```
/loop 7d
```

（`/loop` 不带任务时，会自动执行 `.claude/loop.md` 里写的内容。`7d` = 每 7 天一轮。）

---

## 记住两件事

- **它只在你电脑+Claude Code 开着时转**。关机就停，下次开机再 `/loop 7d` 起来。
- 第一次跑，盯着看它有没有乱动你的笔记。放心了，以后就让它自己转。
- 想升级成「关机也跑、完全不用管」——回对话找我，那一步要把笔记上云，我带你弄。
