# 南宁高校 24h 健身空白区扫描 · 执行手册

> 状态:待执行(等待高德连接器恢复 / 或新会话中通过 .mcp.json 执行)。
> 前置:延安版方法论见《延安健身空白区专项扫描报告》,本手册为南宁复刻版。

## 目标

找出南宁市所有高校周边 **没有 24 小时健身房竞争** 的校区,输出彩色 PDF,
并对 Top 空白校区给出具体候选物业(商业体/沿街底商)。

## 扫描流程(高德 MCP / REST 等价)

1. **高校底册**:`maps_text_search` keywords=大学/学院/职业技术学院,city=南宁,citylimit=true;
   合并研究代理的公开资料底册,按板块分组:
   - 西乡塘·大学路—相思湖(广西大学、广西民族大学、南宁职业技术学院等)
   - 青秀(广西医科大学、广西艺术学院等)
   - 五合大学城(南宁师范大学五合校区、广西外国语学院等)
   - 武鸣教育园区(多所高职新校区)
   - 江南(广西职业技术学院等)
   - 邕宁/龙亭(南宁学院)
2. **逐校区取坐标**:`maps_search_detail`(id 来自步骤 1)。
3. **健身房扫描**:每校区 `maps_around_search` keywords=健身房,radius=1200;
   **24h 判定**:名称含「24」「乐刻」「LikingFit」「光猪圈」「快快」计为 24h 竞品;
   其余计为传统竞品。核心指标 = 1.2km 内 24h 健身房数量(为 0 即空白)。
4. **客群底盘验证**(仅对 24h=0 的校区):`maps_around_search` keywords=住宅小区,radius=1000。
5. **候选物业**(仅对 Top3-5 空白校区):`maps_around_search` keywords=购物中心 / 商业广场,
   radius=1500,记录具体项目名(即"具体物业"建议;面积/层高需实探)。
6. 大城市注意:南宁约 30+ 校区,预计 60-80 次调用;个人 Key 日配额有限,
   分两批跑或次日续跑;`20/20` 截断规则同延安版。

## 彩色 PDF 规格

- 封面:品牌红(#c0392b)+ 深蓝(#1a1a2e)撞色,大标题;
- 校区评级色块:绿(空白·机会)/ 黄(仅传统竞品)/ 红(已有 24h 竞品);
- 板块分布图:reportlab 散点示意图(经纬度归一化),按评级着色;
- 表格:斑马纹 + 评级底色高亮;生成前加载 dataviz 技能校准配色;
- 输出:`docs/site-selection/南宁高校24h健身空白区扫描报告.pdf`。
